# 🎸 Guitardex

O **Guitardex** é uma aplicação web feita para entusiastas da música e guitarristas cadastrarem e compartilharem seus equipamentos e guitarras em uma garagem virtual da comunidade.

---

## 🛠️ Tecnologias Utilizadas

* **Framework PHP:** [Laravel 11](https://laravel.com/)
* **Autenticação:** Laravel Breeze
* **Estilização:** Tailwind CSS
* **Banco de Dados:** MySQL
* **Engine de Templates:** Blade Layouts

---

## ⚡ Funcionalidades Atuais

* **Autenticação Completa:** Cadastro de usuários e login com tema customizado e rotas protegidas.
* **Header Dinâmico:** Identificação do usuário logado e opção de logout.
* **Garagem/Mural Relacional:** Cada usuário logado pode cadastrar e vincular seus próprios equipamentos no banco de dados.
* **Feed da Comunidade:** Listagem pública de todos os equipamentos cadastrados no sistema com informações do proprietário.
